# Release v0.2.1 - ARM64 Support and Documentation Fixes

**Released:** 2026-03-02
**Type:** Patch release (non-breaking)

---

## Highlights

ARM64 binary builds for Linux and documentation link fixes.

---

## What's New

- **ARM64 build support** -- Releases now include an aarch64 Linux binary alongside x86_64, enabling native execution on ARM-based servers
- **Documentation link fixes** -- Fixed broken links in previous release notes; GitHub releases now automatically transform relative links to absolute URLs

---

## Installation

Download the binary for your architecture from the assets below, or see the [Installation Guide](../INSTALLATION.md) for other options.

| File | Architecture |
|------|-------------|
| `ksm-linux-x86_64.tar.gz` | Intel/AMD (x86_64) |
| `ksm-linux-aarch64.tar.gz` | ARM64 (aarch64) |
