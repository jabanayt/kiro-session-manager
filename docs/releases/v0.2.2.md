# Release v0.2.2 - Archive and Search

**Released:** 2026-03-03
**Type:** Patch release (non-breaking)

---

## Highlights

Archive valuable Kiro sessions and search them later with full-text search. Metadata storage migrated from JSON to SQLite.

---

## What's New

- **Session archiving** -- Save conversations for future reference, broken into searchable exchanges with user prompts, assistant responses, and tool summaries
- **Full-text search** -- Search across archived sessions using FTS5 with highlighted matches and expandable results. Supports query syntax: `"exact phrase"`, `AND`, `OR`, `NOT`
- **Archive management** -- Browse with `list-archives`, view full conversations with `show-archive`, inspect single exchanges with `--exchange N`, and remove with `delete-archive`
- **Improved display** -- Coloured labels (green User, blue Assistant, yellow Tools), visual separators between exchanges, truncated assistant content in full archive view, reverse-video search highlighting
- **SQLite metadata storage** -- Metadata migrated from JSON to SQLite with automatic one-time migration on first run. No action required

---

## Technical Changes

- Conversation model refactored to typed enums (ConversationData, UserContent, AssistantContent)
- MetadataStore backed by SQLite with schema versioning and WAL mode
- ArchiveStore with FTS5 full-text search index and content triggers

---

## Upgrading

Existing `metadata.json` data is migrated automatically to `ksm.db` on first run. The original JSON file is preserved but no longer used. JSON migration support will be removed in a future major version.
