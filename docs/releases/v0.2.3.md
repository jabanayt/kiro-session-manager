# Release v0.2.3 - Display Polish and Pager Support

**Released:** 2026-03-03
**Type:** Patch release (non-breaking)

---

## Highlights

Search results and archive views are now easier to read with proper indentation, and long output is automatically paged so it no longer floods the terminal.

---

## What's New

- **Auto-pager** -- Search results and show-archive output is automatically piped through a pager when it exceeds the terminal height. Use `--no-pager` to disable.
- **Search limit raised** -- The default `--limit` on search has been raised from 10 to 50, so more results are visible by default.
- **Version flag** -- `ksm --version` now works as expected.

---

## Bug Fixes

- Multi-line content in search results, show-archive, and expanded exchange views is now properly indented
- Archive tag prompt now shows tags space-separated to match the expected input format
- Session previews with newlines or special characters are collapsed to a single clean line
- FTS5 search syntax and `--limit` flag are now documented in the usage guide

---

## Documentation

- Expanded installation guide with Rust install instructions, GLIBC mismatch note, and source tarball option
- Documented FTS5 query operators, shell quoting, and Porter stemming behaviour
