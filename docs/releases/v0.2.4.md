# Release v0.2.4 - Index vs Archive

**Released:** 2026-03-10
**Type:** Minor release (non-breaking)

---

## Highlights

This release introduces a clear distinction between indexing and archiving sessions. Index keeps sessions active in Kiro while making them searchable; archive preserves sessions permanently after removing them from Kiro.

---

## What's New

- **ksm index** - Make a session searchable while keeping it active in Kiro. Indexed sessions show `[i]` in `ksm list`.
- **ksm unindex** - Remove the search index from a session without affecting the session itself.
- **ksm reindex** - Update search indexes after resuming indexed sessions. Runs automatically by default.
- **Redesigned list display** - Fixed-width columns, compact time format (2s, 5m, 1h, 3d), tags on same line.
- **Index support for archive commands** - `show-archive` and `delete-archive` now accept index numbers from `list-archives`.

### Index vs Archive

| Command | Session in Kiro | Searchable | Use Case |
|---------|-----------------|------------|----------|
| `ksm index` | Kept | Yes | Active sessions you want to search |
| `ksm archive` | Deleted | Yes | Completed sessions to preserve |

**Before:** `ksm archive` kept sessions in Kiro (confusing name).
**After:** `ksm archive` now deletes from Kiro after indexing. Use `ksm index` to keep sessions active.
**Impact:** Clearer mental model matching user expectations.

---

## Bug Fixes

- Search queries with punctuation (periods, commas, hyphens) no longer cause FTS5 syntax errors
- `show-archive` now accepts index numbers as well as archive names
- `pending_reindex` flag now cleared when `auto_update` config is disabled

---

## Technical Changes

- Unified `KsmDatabase` replaces separate metadata and archive stores
- Row-level database operations instead of load-all/save-all pattern
- Centralised `styles` module for consistent colours across commands
- Services receive directory as parameter (improved testability)
- Schema v3 migration adds `is_indexed` column and `state` table
- Release binaries now built on Ubuntu 22.04 for wider compatibility

---

## Upgrading

Database migration runs automatically on first use. Your existing archives are preserved and marked as archived (not indexed).

New config option available:

```toml
[index]
auto_update = true  # Default: automatically reindex after resuming
```

## Known Issues

- When using `ksm index`, you're prompted for a name and tags. These are stored for search results and become the archive name if the session is later deleted. However, `ksm list` shows the session's metadata name, not the index name. A future release will streamline this.
