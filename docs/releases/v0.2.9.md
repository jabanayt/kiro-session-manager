# Release v0.2.9 - Duplicate Session Fix

**Released:** 2026-04-15
**Type:** Patch release (non-breaking)

---

## Highlights

This release fixes a critical bug where deleting one of two duplicate sessions (v1/v2 with the same ID) would incorrectly remove metadata for both sessions.

---

## Bug Fixes

- **Duplicate session deletion** When two sessions exist with the same ID (v1 and v2 variants), deleting one no longer removes metadata for both. Session deletion now properly preserves metadata for the remaining session.

## Technical Changes

- Metadata deletion now uses composite key `(session_id, source_type)` instead of `session_id` alone

## Known Issues

- When using `ksm index`, you are prompted for a name and tags. These are stored for search results and become the archive name if the session is later deleted. However, `ksm list` shows the session metadata name, not the index name. A future release will streamline this.
